# DriftLabe — журнал изменений

## Исходный аудит

- Архив содержал React + Three.js игру на Vite/TypeScript, существующую F2-консоль, физическую модель в `app/src/game/physics.ts`, ввод в `app/src/game/input.ts` и настроенный GitHub Actions workflow для Pages.
- Источник мышиного руля уже использовал `movementX` при Pointer Lock. Скоростной предел передних колёс вычислялся интерполяцией по скорости.
- F2 уже содержала все параметры из `CAR` и отдельную настройку `peakTorque` в Н·м; расчёт двигателя использовал её непосредственно при вычислении момента на задних колёсах.
- Недоставало централизованной deadzone и сглаживания мышиного ввода; каталог F2 не перечислял каждую настройку и влияние.

## Изменения

- Добавлены регулируемые deadzone 4 px и сглаживание мыши с временной постоянной 0,055 с. Порог применяется к виртуальному перемещению курсора, не к каждому событию по отдельности, поэтому последовательность небольших дельт не теряется.
- Сглаженный сигнал обновляется фиксированным шагом физики. При выходе из Pointer Lock мышь возвращается к центру по прежней настройке, теперь через тот же фильтр.
- Приближённый к нулю рулевой ввод и угол колёс явно защёлкиваются в `0`, устраняя signed zero в HUD.
- Существующие мышиные настройки и F2-параметры сохранены; чувствительность мыши переименована в интерфейсе для ясности.
- Пиковый момент остался единственной настройкой мощности: его уже использует расчёт крутящего момента двигателя; поле переименовано для понятности и помечено как влияющее на разгон.
- Добавлены полный каталог параметров F2, аудит управления и руководство по загрузке/Pages в документации.

## Проверка и деплой

- Команда сборки проекта: `cd app && npm ci && npm run build` (точная установка из lock-файла, TypeScript и production build Vite).
- GitHub Actions запускается при push в `main` или вручную (`workflow_dispatch`), публикует `app/dist/public` в GitHub Pages и печатает URL в job summary.
- Деплой не запускался: для него требуется отправить файлы в личный GitHub-репозиторий и разрешить GitHub Pages через GitHub Actions.
